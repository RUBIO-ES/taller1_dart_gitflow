# Taller 1: Dart + Gitflow (Catálogo de Productos)
Realizado por: Dayana Andrea Cárdenas Gómez
Aplicación de consola en Dart para la gestión de productos mediante un CRUD, implementando la metodología de ramas Gitflow.


## 🚀 Funcionalidades
- **Agregar producto:** Nombre, Precio y Cantidad.
- **Listar productos:** Muestra la lista formateada con índices.
- **Actualizar producto:** Permite modificar datos individualmente sin perder los anteriores.
- **Eliminar producto:** Elimina el ítem seleccionado por índice.
- **Validaciones:** Control de entradas nulas, precios no válidos e índices fuera de rango.

## 🛠️ Tecnologías
- Git & Gitflow
